How the run will be ordered
  • seed: runs first, one after another, right after POST /api/reset. These check the original seed data before anything changes it.
  • parallel: runs in as many browsers as the machine allows. Each test creates its own data and finds it by the captured reference number.
  • stateful: runs last, one after another, because it checks global counters (dashboard pending count) that parallel tests would change.
  • Source AI Lens cases come from that report's suspected defects, so several are expected to fail today. That is the point: they confirm or clear each finding on the live app.
